# InGen - Learn Smarter, Together

A production-ready, full-stack learning management platform built with Next.js 14, TypeScript, Tailwind CSS, Supabase, and Google Gemini AI.

![InGen Landing Page](./docs/landing.png)

## Tech Stack

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS
- **UI**: Custom glassmorphism design system + Lucide icons + Framer Motion animations
- **Backend**: Next.js API Routes (Route Handlers)
- **Database**: Supabase (PostgreSQL) with Row Level Security
- **Authentication**: Supabase Auth (email/password)
- **File Storage**: Supabase Storage (bucket: "library-files")
- **AI**: Google Gemini API (gemini-2.0-flash model)

## Features

### Core Features
- **Dashboard** — Stats overview, class carousel, today's schedule, study analytics with streak calendar
- **Classes** — Create/join classrooms with 6-character codes, manage members, share files
- **Library** — Upload & manage files (PDF, DOCX, TXT, images), AI-powered summaries
- **Calendar** — Weekly timetable, AI-generated study schedules, Google Calendar integration
- **AI Tutor** — Chat with Gemini AI, quiz mode, markdown rendering, chat history
- **Flashcards** — AI-generated flashcards from notes, 3D flip cards, spaced repetition
- **Settings** — Profile management, dark/light theme, integrations

### Premium Features
- **Pomodoro Timer** — Floating timer widget accessible from any page
- **Command Palette** — Cmd+K global search and navigation
- **Study Analytics** — Weekly hours chart, streak calendar, productivity insights
- **Collaborative Notes** — Shared notes within classes
- **Quiz Mode** — Interactive multiple-choice quizzes generated by AI

## Quick Start

### Prerequisites
- Node.js 18+
- Supabase account (free tier works)
- Google Gemini API key (free tier)

### 1. Clone and Install

```bash
cd ingen
npm install
```

### 2. Set Up Supabase

1. Create a new Supabase project at [supabase.com](https://supabase.com)
2. Go to SQL Editor and run the migration file: `supabase/migration.sql`
3. Go to Storage and create a bucket called `library-files` with public access
4. Copy your project URL, anon key, and service role key

### 3. Set Up Gemini API

1. Get a free API key at [ai.google.dev](https://ai.google.dev)
2. Use the `gemini-2.0-flash` model (free tier)

### 4. Configure Environment

Copy `.env.local` and fill in your keys:

```bash
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
GEMINI_API_KEY=your-gemini-api-key
```

### 5. Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

### Admin Access

Use the built-in admin account for instant access:
- **Email**: `admin@g`
- **Password**: `admin1`

The admin account auto-creates on first login and seeds demo data (3 classes, library files, calendar events, AI chat history, study streak).

## Database Schema

The app uses 12 tables with full Row Level Security:

- `profiles` — User profiles extending Supabase Auth
- `classes` — Classrooms with join codes
- `class_members` — Many-to-many class membership
- `library_files` — File metadata with AI summaries
- `calendar_events` — Weekly timetable events
- `exams` — Upcoming exam dates
- `ai_chats` — AI conversation sessions
- `ai_messages` — Individual chat messages
- `study_streaks` — Daily study tracking
- `flashcard_decks` — Flashcard collections
- `flashcards` — Individual flashcard items
- `class_notes` — Collaborative class notes

## API Routes

24 fully implemented API endpoints handling auth, classes, library, calendar, AI tutor, flashcards, profile, stats, exams, and data seeding. All routes use the Supabase service client with proper error handling.

## Design System

- **Glassmorphism**: Frosted glass cards with `backdrop-blur-xl`
- **Animated gradient backgrounds**: Light blue → lavender → pale pink
- **Dark mode**: Deep charcoal with blue-tinted surfaces
- **Accent**: Vivid cyan-blue gradient
- **Typography**: Inter font family
- **Animations**: Framer Motion for all transitions
- **Responsive**: Mobile-first with sidebar (desktop) and bottom tabs (mobile)
